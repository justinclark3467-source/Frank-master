# CLIENT FOLDER TEMPLATE

## Structure
```
client-name/
├── content/        # Posts, videos, copy
├── analytics/      # Reports, metrics
├── contracts/      # Agreements, invoices
└── assets/         # Logos, images, brand guides
```

## For each new client:
1. Duplicate this folder
2. Rename to client name
3. Fill in their info

## What's stored here:
- Content calendar (what's posted when)
- Performance reports (weekly)
- Client communications
- Contract details
- Brand assets
