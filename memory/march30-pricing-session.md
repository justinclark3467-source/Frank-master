## COST ANALYSIS (Per Client)

### Cost Assumptions (Monthly)
- API tokens (content): ~$0.05-0.20/client
- Video credits (A2E bulk): ~$0.005/credit
- Short link/clicks: Free (Bitly/Short.io free tier)
- Notion CRM: Free (our own instance)
- Google Voice: Free (client-provided or free)

### Tier 1: Starter Launch ($34.99/mo)
- Posts: 12/month (8 static + 4 video)
- Cost: 4 video posts x 2 versions = 8 versions x 120 credits = 960 credits x $0.005 = $4.80 + ~$0.05 API = ~$4.85
- Profit: $34.99 - $4.85 = $30.14 (86% margin)

### Tier 2: Starter ($49/mo)
- Posts: 12/month
- Cost: ~$4.85
- Profit: $49 - $4.85 = $44.15 (90% margin)

### Tier 3: Standard ($79/mo)
- Posts: 24/month (16 static + 8 video)
- Cost: 8 video x 2 versions = 16 versions x 120 = 1,920 credits x $0.005 = $9.60 + ~$0.08 API = ~$9.68
- Profit: $79 - $9.68 = $69.32 (88% margin)

### Tier 4: Pro ($129/mo)
- Posts: 60/month (30 static + 30 video)
- Cost: 30 video x 2 versions = 60 versions x 120 = 7,200 credits x $0.005 = $36 + ~$0.15 API = ~$36.15
- Profit: $129 - $36.15 = $92.85 (72% margin)

### Tier 5: Full Service ($199/mo + $500 setup)
- Posts: 60/month + AI bot
- Monthly cost: Same as Pro (30 video) = $36 + sub-agent API ~$5-10 = ~$45/mo
- Setup one-time: $500 covers initial setup (1-2 hours: profiles, Notion, calendar)
- Profit: $199 - $45 = $154/mo (77% margin)
